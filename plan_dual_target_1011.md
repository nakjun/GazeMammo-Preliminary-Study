# 시선 NLL과 병변 확보율의 두 목표를 위한 반복 실험

사용자가 2026년10월11일 지정한 종료 조건은 **시선 예측 NLL5.3 이하와 병변 확보율85% 이상을 모두 충족**하는 것이다. 개발과 실험은 GPT-6.1-Sol low 서브에이전트가 진행한다. 이전의 상대10% 표현보다 이후 지정한 두 절대 임계값을 우선한다.

## 고정한 평가 조건

NLL은 기존과 같은24×48grid에서 legacy16 관측 경로의 다음 cell 확률을 평가한다. 이전 좌표와 이전224px crop만 조건으로 사용하며, 영상별 유효 step을 평균한 뒤 validation93장 평균을 낸다. Target 양자화와 코호트를 바꾸어 NLL을 낮추지 않는다. NLL은 확률 예측 모델의 지표이고, 강제 ROI reservation 자체가 NLL을 개선했다고 주장하지 않는다.

병변 확보율은16개의 실제224px crop 중 적어도 하나가 GT box 면적의50% 이상을 포함한 비율이다. 여러 병변이 있으면 영상 내 병변별 비율을 먼저 평균하고93장 평균을 낸다. 기본 확정은 generation seeds42/43/44의 영상별 평균을 사용한다. 최대 달성 coverage로 보정한 Recall50과 실제 box50% recall은 다른 지표다. 목표85%는 후자다.

Gaze 모델의 확률 예측과 그 출력을 이용한 ROI patch 선택 정책을 각각 명시하고, 최종 하나의 재현 가능한 pipeline에서 두 평가를 수행한다. ROI 선택에서 원 proposal을 재사용하면 원 projection과 proposal head를 함께 고정한 별도 memory를 사용한다. 새 gaze projection의 keys에 원 proposal head를 적용하지 않는다.

Validation93장은 반복 검토한 개발 코호트다. 독립 test와 INbreast quarantine은 설정 탐색에 쓰지 않는다. 목표 달성은 이 개발 평가에서의 달성으로 보고하고, 최종 독립 검증은 구분한다. 평균 목표를 충족하는지와 환자 단위 CI를 별도로 보고한다.

## 현재 기준과 달성 가능한 범위

[완료한 첫 비교](runs/proposal_visit_1011/report.md)에서 원 combined 모델의 guided NLL은5.907845다. 같은 모델에서 proposal의 서로 다른 상위3crop을 먼저 선택하고 나머지13step을 sampling한 정책이 우수했다.

|---|---:|---:|
| 실제 box50% recall | 53.05% | 77.96% |
| 최대 가능 coverage 기준 Recall50 | 72.76% | 93.73% |
| 평균 실제 최대 box coverage | 51.28% | 70.03% |
| Sampling normalized DTW | 0.126048 | 0.124362 |

DTW 차이의 CI는0을 포함한다. P5는 선택 heuristic이고 NLL을 보고하지 않는다. 원 proposal을 다시 학습한 occupancy/MSE head의 P5는 실제 recall74.55%, crop utility/MSE head의 P5는77.78%였다. 현재 새 head가 원 proposal의 선택 성능을 개선했다는 근거는 부족하다.

[Geometry oracle](runs/proposal_visit_1011/oracle_feasibility/oracle_bounds.json)에서224px 단일 crop의 실제 box50% recall 최대값은 **86.02%**다. 이는 각 병변에 최적인 grid crop을 독립적으로 고르는 낙관적인 상한이며 실제16patch 정책의 성능이 아니다.85%는 이 상한의98.81%에 해당하므로 어렵지만 이 기하학적 상한만으로 불가능하다고 판정할 수 없다.

256px crop의 상한은92.47%,320px 이상은98.92%지만, crop 면적이 각각1.31배와2.04배 이상 증가한다. 우선224px를 유지한다. 이후 crop 확대를 실험하면 같은 확대 crop의 기준군을 함께 평가하고 추가 영상 면적의 효과를 분리한다. 확대 결과를 동일224px 조건의 성능 향상으로 보고하지 않는다.

## 병변 확보율을 높이는 실험

원 proposal을 고정하고 예약할 서로 다른 crop 수 K를0/1/2/3/4/6/8/12/16으로 비교한다. 전체 예산은 항상16개다. 기존 crop IoU0.3을 넘는 후보를 순차 제외하며, 남은 step은 실제 선택된 history의 conditional gaze 분포에서 sampling한다.

선택 순서는 처음 K개를 예약하는 방식과 경로에 균등하게 배치하는 방식을 비교한다. K3의 분산 배치는 step1/6/11이다. K0과 K16은 두 배치가 같으므로 중복 실행하지 않는다. 최초 pilot은 seed42이고,85%에 도달한 후보를3generation seeds에서 다시 평가한다. 초기 seed42 결과만으로 종료하지 않는다.

K를 늘려도85%에 미달하면 후보 공간과 crop overlap 억제 강도를 검토한다. GT box를 후보 생성이나 예약 순서에 넣지 않는다. 과도한 예약으로 gaze 유사성이 나빠질 수 있으므로 DTW·고유 위치수·foreground를 함께 기록한다. ROI 예약이 확률 모델의 NLL 개선을 대신하지 않는다.

신규 구현은 [proposal_budget_1011.py](src/proposal_budget_1011.py)와 [CLI](scripts/proposal_budget_1011.py)다. 현재 [224px pilot 상태](runs/dual_target_1011/budget224_seed42_state.json)를 확인한다. Thin trace에는 좌표, 선택 index, proposal과 필요한 분포 요약만 저장해 큰 분포 배열의 반복 저장을 줄인다.

## 시선 예측 NLL을 낮추는 실험

기존 guided 학습은 box 관련 목적과 gaze 모방을 함께 최적화했고, best의 raw NLL은6.187456이다. 원 human control/improved checkpoint와 guided checkpoint의 raw 모델을 비교한 뒤 사람 경로 hard NLL에 직접 적응한다.

먼저 온도0.5/0.75/1/1.25/1.5/2에서 확률 보정을 비교한다. Proposal을 포함하는 기존 guided 모델의 보정은 별도로 기록한다. 이 보정은 반복 열람한 validation에 맞춘 exploratory calibration이다.

다음으로 같은 legacy16 target을 사용하여 frozen visual encoder의 projection과 decoder를15epoch 학습한다. Gaussian CE를 제거한 hard NLL과 prior 계수0 또는0.1을 비교하고, human control/improved/guided raw 초기화의6군을 검사한다. 같은 seed와 optimizer 조건을 기록하며 val NLL로 best를 선택한다. 박스 감독과 ROI 방문 loss는 이 단계에서 추가하지 않는다.

Visual feature cache는 projection 이전 pyramid와 관측된 직전 crop의 encoder vector를 저장한다. Train412장과 val93장의 allowlist, 이미지 및 gaze source hash, encoder hash를 검증한다. 시각 encoder가 같은 초기화만 cache를 공유한다. 실제 이미지 forward와 cache 기반 teacher 결과의 일치 및 compact restore를 검사한다.

신규 [NLL adaptation 모듈](src/gaze_nll_adaptation_1011.py), [CLI](scripts/gaze_nll_adaptation_1011.py), [실행기](scripts/run_gaze_nll_trials_1011.py)가 구현됐다. [학습 상태](runs/gaze_nll_adaptation_trials_1011_v2/status.json)를 확인한다. 첫 실행은 잘못된 manifest train count를 guard가 탐지해 feature 추출 전에 중단됐으며, 수정한 실행은 all.csv train412와 trajectory.csv val93을 사용한다.

병렬로 원 이미지 기반 분포와 과거 위치의 local/velocity/return expert를 결합하는 작은 모델을 검토한다. 현재 행동 mixture가 global branch에 치우친 기록이 있으므로, 같은 target에서 history 활용으로 얻는 이득을 분리한다. Mixture weights·scale·temperature는 train만으로 학습하고 val에 평가한다. 미래 gaze나 현재 정답 위치를 expert 입력에 전달하지 않는다.

## 종료 판정과 기록

후보 NLL이5.3 이하가 되면 실제 이미지와 관측 prefix에서 cache 없이 재계산하고 source hash·target·mask·환자 cohort를 검증한다. ROI85% 후보도 원본 이미지에서 동일224px crop/16patch/3generation seeds로 확인한다. 새 gaze 모델을 ROI 정책에 연결한 뒤 두 조건을 다시 검사한다. 이전 gaze 모델의 ROI 결과와 새 모델의 NLL을 서로 다른 구성에서 가져와 종료하지 않는다.

실험별 train loss, val NLL, 실제 box50% recall, sampling/argmax 차이, crop 크기, 예약 예산, 초기화와 선택 provenance를 남긴다. 두 조건을 충족하기 전에는 목표를 완료한 것으로 표시하지 않는다. 실패한 실험도 결과를 보존하며 다음 실험은 확인된 병목을 바꾸는 방식으로 진행한다.

Canonical16 학습 대조군과 resampled16군에 동일 optimizer·epoch·initialization을 사용하며, KL teacher도 동일한 augmented causal prefix를 입력받는다.
